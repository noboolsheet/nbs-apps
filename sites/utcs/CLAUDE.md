# CLAUDE.md

## Design Context

This project has impeccable design context. Read these before any UI work:

- **`PRODUCT.md`** — strategy. Register: **brand** (institutional/marketing site for UTCS, an accredited Italian business association: CAF, Patronato, APL, formazione). Primary audience: PMI/imprenditori → become an associato. Personality: **moderno · affidabile · concreto**.
- **`DESIGN.md`** — visual system. North Star: **"The Modern Civic Standard."** **Official brand palette (non-negotiable): green `#3A783B`, red `#E91C34`, white `#FFFFFF`.** Playfair Display headings + Inter body; OKLCH tokens in `src/styles.css`; refined & restrained components.

**Design principles (from PRODUCT.md):**
1. Chiarezza prima dell'eleganza.
2. Credibilità per prova, non per aggettivi.
3. Efficienza percepita.
4. Italianità con misura (tricolore come sigillo, non decorazione).
5. Rispetto per l'utente non tecnico (WCAG 2.1 AA).

**Anti-references:** dated public-sector/PA portals; generic SaaS templates.

For design/UI tasks use the `/impeccable` skill (commands: craft, critique, audit, polish, …).
